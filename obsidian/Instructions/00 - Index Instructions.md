# Instructions

Les règles que l'IA doit respecter pour produire le jeu, par domaine. Elles sont lues à la demande, au début d'une tâche du domaine concerné.

Le reste du vault décrit le jeu lui-même : [[00 - Index DA]] (style, source de vérité), [[00 - Index Fonctionnalités]] (ce qui existe), [[00 - Index À faire]] (ce qui reste).

## Domaines
- [[00 - Index Pipeline 3D]] : modélisation et animation des modèles, de Blender à Unity. À lire avant toute session de modélisation, avec la DA.
- [[00 - Index Code]] : organisation et conception du code Unity. À lire avant d'écrire ou de modifier du code.

## Règles communes
- Une règle n'est écrite qu'à un seul endroit. Les règles valables pour toutes les sessions (langue, Git, graphify, conventions du vault, mise à jour des tâches) sont dans le `CLAUDE.md` à la racine du projet, chargé automatiquement : ces notes ne les répètent pas.
- Tout ce qui relève du style va dans la Direction Artistique, jamais ici. En cas de contradiction, la DA l'emporte.
