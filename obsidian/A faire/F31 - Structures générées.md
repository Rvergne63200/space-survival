# F31 - Structures générées

**Structures** générées dans le monde (épaves, ruines, capsules…). Les capsules générées doivent recevoir un id déterministe (`SaveableObject.SetGeneratedId`, comme `EnvironmentSpawner`), pour que leur intérieur soit sauvegardé.

Voir aussi : [[Capsule de départ]] · [[Sauvegarde]]
