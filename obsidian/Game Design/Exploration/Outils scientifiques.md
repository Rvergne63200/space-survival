# Outils scientifiques

## Scanner
- Le joueur dispose d'un **scanner**.
- Son usage en jeu n'est pas décrit dans le concept (voir [[Points ouverts du game design]]). La DA le présente comme une interface holographique qui révèle les traces de vie, les ressources et les données ([[08 - Technologie humaine#Outils du joueur]]).

## Table d'observation
- Une **table d'observation** pour **étudier les fossiles, les roches et les échantillons divers**.

Mise en scène des découvertes : [[07 - Traces de vie ancienne]].
