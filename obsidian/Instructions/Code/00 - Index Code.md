# Code Unity

Les règles que l'IA respecte pour organiser et concevoir le code du jeu. À lire avant d'écrire ou de modifier du code, avec la note [[00 - Index Fonctionnalités|Fonctionnalités]] de la feature concernée. Retour à [[00 - Index Instructions]].

Ces notes disent **comment faire**. Le comportement de ce qui existe est décrit dans les Fonctionnalités : ces notes y renvoient au lieu de le répéter. Les règles valables pour toutes les sessions (langue, Git, graphify, vérification de base, `.meta`, scripts d'animation des modèles) sont dans `CLAUDE.md`.
